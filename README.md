# 학교 행사 참여 기록

설치 없이 웹 브라우저로 쓰는 앱입니다. 자료는 **구글 시트**에 저장되고, 화면은 **GitHub Pages·Vercel**로 배포합니다.

## 폴더 구성

```
school-events-app/        ← 이 폴더 내용 그대로 GitHub 저장소 맨 위에 둡니다
├─ index.html             웹 화면 뼈대
├─ style.css              화면·인쇄 디자인
├─ app.js                 앱 기능 전부
├─ config.js              학교 이름, Apps Script 웹 앱 주소(API_URL)
├─ README.md              이 안내
└─ apps-script/
   └─ Code.gs             구글 시트의 Apps Script에 붙여 넣는 서버 코드 (웹 배포와 무관)
```

- 웹 화면을 고치면 → `app.js`, `style.css`만 바뀝니다. GitHub에 올리면 **GitHub Pages와 Vercel이 함께 자동 배포**됩니다.
- `Code.gs`를 고쳤을 때만 → Apps Script에 붙여 넣고 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포** (주소는 그대로).
- `config.js`의 `API_URL`이 비어 있으면 예시 데이터로 도는 **체험 모드**가 됩니다. 저장소의 `config.js`에는 반드시 웹 앱 주소가 들어 있어야 합니다.

## 고친 내용 올리기 (GitHub 웹)

1. 저장소 → **Add file → Upload files** → 바뀐 파일을 끌어다 놓기 → **Commit changes**
2. 1~2분 뒤 **Actions** 탭(GitHub Pages)과 Vercel 대시보드에서 배포 완료 확인
3. 예전 화면이 보이면 **Ctrl+F5** (강력 새로고침)

## 처음 설치할 때

### 1. 구글 시트 + Apps Script
1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣고 저장
3. 함수 선택 칸에서 **setup** → **실행** → 권한 허용 (계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용)
4. **실행 로그**에 나온 두 코드를 메모 — **조회 코드**(담임용, 보기만) / **편집 코드**(자료 올리는 선생님용)
5. **배포 → 새 배포 → 웹 앱** / 실행 사용자: **나** / 액세스: **모든 사용자** → 나온 **웹 앱 URL**을 `config.js`의 `API_URL`에 넣기

### 2. 웹 배포
- **GitHub Pages**: 저장소 → Settings → Pages → Branch: `main` / `/(root)` → Save → `https://아이디.github.io/저장소이름/`
  (무료 계정은 저장소가 Public이어야 함 — 학생 자료는 구글 시트에만 있고 저장소에는 코드만 올라갑니다.)
- **Vercel**: Add New → Project → 저장소 Import → Framework Preset **Other** → Deploy
  (index.html이 저장소 맨 위에 있어야 합니다. 폴더 안에 있으면 Root Directory를 그 폴더로 지정)

## 사용 방법

- **학생별 조회** — 학년·반 → 학생을 누르면 참여 행사가 날짜순으로 나옵니다. 생기부 문구 복사, 인쇄, 엑셀(CSV) 내려받기.
- **행사 관리** — 대상이 **전체 학생**이면 (해당 학년) 모든 학생에게 자동 표시, **참여 학생만**이면 반별 체크나 붙여넣기로 등록.
  붙여넣기는 학번(`1107`), `3학년 2반 7번`, `3 2 7`, 엑셀 학년·반·번호 열 모두 인식합니다.
- **명단·가져오기** — 새 학년도 학생 명단(학번, 이름)을 붙여 넣어 올리기. 학번은 4자리(`1101` = 1학년 1반 1번)이며 5자리도 인식합니다. 학년도별로 저장됩니다.
- **새로고침** — 다른 선생님이 고친 내용 불러오기.

## 관리 팁

- 구글 시트(`행사`, `학생`, `참여` 탭)를 직접 고쳐도 앱에 반영됩니다. 시트의 *버전 기록*으로 되돌릴 수도 있습니다.
- 접속 코드 변경: Apps Script의 `changeCodes()` 안 값을 고친 뒤 그 함수를 실행 (재배포 불필요).
  **실제 코드를 적은 `Code.gs`는 GitHub에 올리지 마세요.** (저장소가 공개라 누구나 볼 수 있습니다.)
- 구글 시트 자체는 다른 사람과 공유하지 않아도 됩니다. 앱은 시트 주인 권한으로 동작합니다.
