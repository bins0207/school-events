# 학교 행사 참여 기록 — 설치 안내

설치 없이 웹 브라우저로 쓰는 앱입니다. 자료는 **구글 시트**에 저장되고, 화면은 **Vercel**에서 무료로 띄웁니다.

```
[선생님들 브라우저] ──▶ [Vercel 웹 화면] ──▶ [Apps Script] ──▶ [구글 시트]
```

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 웹 화면 (고칠 필요 없음) |
| `config.js` | **학교 이름, API 주소 입력** |
| `apps-script/Code.gs` | 구글 시트에 붙일 서버 코드 |
| `행사기록_시작데이터.xlsx` | 2023 엑셀 자료를 새 형식으로 옮긴 시작 파일 |

---

## 1단계. 구글 시트 만들기 (5분)

1. 구글 드라이브에 `행사기록_시작데이터.xlsx`를 올린 뒤, 파일을 열고 **파일 → Google 스프레드시트로 저장**을 누르세요.
   (빈 시트로 시작하려면 새 스프레드시트를 만들면 됩니다.)
2. 새로 생긴 구글 시트에서 **확장 프로그램 → Apps Script**를 여세요.
3. 원래 있던 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장(💾)하세요.
4. 위쪽 함수 선택 칸에서 **setup**을 고르고 **실행**을 누르세요.
   - 처음 한 번은 권한 허용 창이 뜹니다: 계정 선택 → *고급* → *(안전하지 않음)으로 이동* → 허용
   - 아래 **실행 로그**에 두 가지 코드가 나옵니다. 메모해 두세요.
     - **조회 코드**: 담임 선생님께 알려 줄 코드 (보기만 가능)
     - **편집 코드**: 자료를 올리고 고치는 선생님용 코드

## 2단계. 웹 앱으로 배포 (3분)

1. Apps Script 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 ⚙ → **웹 앱** 선택
3. 설정
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사하세요.

> "모든 사용자"로 해도 접속 코드를 모르면 자료를 볼 수 없습니다.
> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로)

## 3단계. GitHub에 올리기 (3분)

1. github.com에서 **New repository** → 이름 예: `school-events` → **Private** 선택 → Create
2. **uploading an existing file** 링크를 눌러 이 폴더의 파일을 모두 끌어다 놓기
   (`index.html`, `style.css`, `app.js`, `config.js`, `README.md`, `apps-script` 폴더)
   - 시작데이터 엑셀은 학생 정보가 있으니 **올리지 마세요.**
3. 올린 `config.js`를 GitHub에서 열고 ✏(연필)을 눌러 수정:
   ```js
   SCHOOL_NAME: "○○고등학교",
   API_URL: "2단계에서 복사한 웹 앱 URL",
   ```
   → **Commit changes**

## 4단계. Vercel로 띄우기 (2분)

1. vercel.com → **Add New… → Project** → 방금 만든 GitHub 저장소 **Import**
2. Framework Preset: **Other** (빌드 설정은 그대로) → **Deploy**
3. 생긴 주소(예: `school-events.vercel.app`)를 선생님들께 공유하세요.

이후 GitHub에서 파일을 고치면 Vercel에 자동으로 다시 배포됩니다.

## 사용 방법

**학생별 조회** — 학년·반을 고르고 학생을 누르면 참여한 행사가 날짜순으로 나옵니다.
생기부 공통 문구를 하나씩 또는 한꺼번에 복사할 수 있고, *반 전체 인쇄*로 예전 '개별 자료'처럼 학생별 한 장씩 출력됩니다.

**행사 관리** — 행사명, 분류, 대상, 기간, 주관부서, 활동 내용, 생기부 문구를 입력합니다.
- 대상이 **전체 학생**이면 명단 없이 (해당 학년) 모든 학생에게 자동 표시됩니다.
- **참여 학생만**이면 반별로 체크하거나, 엑셀에서 학번 열을 복사해 붙여 넣어 등록합니다.

**명단·가져오기** — 새 학년도가 되면 그 해 학생 명단(학번, 이름)을 붙여 넣어 올립니다.
학번은 해마다 바뀌므로 명단은 학년도별로 따로 저장됩니다. 여러 행사를 엑셀에서 한꺼번에 가져올 수도 있습니다.

**새로고침** — 다른 선생님이 같은 시간에 고친 내용을 불러옵니다.

## 관리 팁

- 구글 시트(`행사`, `학생`, `참여` 탭)를 직접 고쳐도 앱에 그대로 반영됩니다. 시트의 *버전 기록*으로 되돌리기도 가능합니다.
- 접속 코드를 바꾸려면 Code.gs의 `changeCodes()` 안 값을 고친 뒤 그 함수를 실행하세요. (배포는 다시 하지 않아도 됩니다.)
- 학생 개인정보가 담기므로 구글 시트는 다른 사람과 **공유하지 않아도** 됩니다. 앱은 시트 주인 권한으로 동작합니다.
- `config.js`의 `API_URL`을 비워 두면 예시 데이터로 동작하는 **체험 모드**가 됩니다.
