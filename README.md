# 학교 행사 참여 기록 — 설치 안내

설치 없이 웹 브라우저로 쓰는 앱입니다. 자료는 **구글 시트**에 저장됩니다.

## ✅ 방법 A (추천): 구글만으로 끝내기 — GitHub·Vercel 필요 없음

필요한 파일은 `apps-script` 폴더의 **`Code.gs`, `Index.html` 두 개**뿐입니다.

### 1. 구글 시트 만들기
1. 구글 드라이브에 `행사기록_시작데이터.xlsx`를 올리고, 열어서 **파일 → Google 스프레드시트로 저장**
   (빈 시트로 시작해도 됩니다.)
2. 그 구글 시트에서 **확장 프로그램 → Apps Script** 열기

### 2. 코드 넣기
1. 왼쪽 `Code.gs`의 내용을 모두 지우고, 받은 **`Code.gs`** 내용을 붙여 넣기
2. 왼쪽 **파일 옆 `+` → HTML** → 이름을 정확히 **`Index`** 로 입력 (`.html`은 자동으로 붙음)
3. 새로 생긴 `Index.html`의 내용을 모두 지우고, 받은 **`Index.html`** 내용을 붙여 넣기
   - 학교 이름은 `Index.html`에서 `SCHOOL_NAME: "우리 고등학교"` 부분을 고치세요.
4. 저장(💾 또는 Ctrl+S)

### 3. 처음 설정
1. 위쪽 함수 선택 칸에서 **setup** → **실행**
2. 권한 허용 창: 계정 선택 → **고급** → **(안전하지 않음)으로 이동** → **허용**
   (내가 만든 스크립트라 구글 검증이 없어 나오는 안내입니다.)
3. 아래 **실행 로그**에 나온 두 코드를 메모
   - **조회 코드** → 담임 선생님용 (보기만)
   - **편집 코드** → 자료 올리고 고치는 선생님용

### 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 ⚙ → **웹 앱**
2. 실행 사용자: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
   - 학교 구글 워크스페이스 계정이면 **"○○학교 내 모든 사용자"** 를 골라도 됩니다. (더 안전, 대신 학교 계정 로그인 필요)
3. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)이 앱 주소입니다. 선생님들께 공유하세요.

> 주소가 길면 bit.ly 같은 단축 주소나 QR 코드로 만들어 공유하면 편합니다.
> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포** 해야 반영됩니다. (주소는 그대로)

## 방법 B (선택): 별도 웹 주소로 띄우기 — GitHub Pages 또는 Vercel

`index.html`, `style.css`, `app.js`, `config.js`를 GitHub 저장소에 올리고 `config.js`의 `API_URL`에 방법 A의 웹 앱 URL을 넣습니다.

- **GitHub Pages**: 저장소 → Settings → Pages → Branch: `main` / `/(root)` → Save. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다. (무료 계정은 저장소가 **Public**이어야 함 — 학생 자료는 구글 시트에 있으니 코드만 공개됩니다.)
- **Vercel**: Add New → Project → 저장소 Import → Framework Preset **Other** → Deploy. (index.html이 저장소 맨 위에 있어야 합니다. 폴더 안에 들어가 있으면 Root Directory를 그 폴더로 지정)

## 사용 방법

- **학생별 조회** — 학년·반 → 학생을 누르면 참여 행사가 날짜순으로 나옵니다. 생기부 문구 복사, 반 전체 인쇄·엑셀(CSV) 내려받기.
- **행사 관리** — 대상이 **전체 학생**이면 (해당 학년) 모든 학생에게 자동 표시, **참여 학생만**이면 반별 체크나 학번 붙여넣기로 등록.
- **명단·가져오기** — 새 학년도 학생 명단(학번, 이름)을 붙여 넣어 올리기. 학번은 해마다 바뀌므로 학년도별로 저장됩니다.
- **새로고침** — 다른 선생님이 고친 내용 불러오기.

## 관리 팁

- 구글 시트(`행사`, `학생`, `참여` 탭)를 직접 고쳐도 앱에 반영됩니다. 시트의 *버전 기록*으로 되돌릴 수도 있습니다.
- 접속 코드 변경: Code.gs의 `changeCodes()` 안 값을 고친 뒤 그 함수를 실행 (재배포 불필요).
- 구글 시트 자체는 다른 사람과 공유하지 않아도 됩니다. 앱은 시트 주인 권한으로 동작합니다.
